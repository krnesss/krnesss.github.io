# 三角洲行动 · 改枪码

玩家整理的三角洲行动改枪方案站：按枪械分类浏览**改枪码**、**方案概览图**和**各项属性**。

**网址：<https://krnesss.github.io/>**

---

## 有些什么

- **分类浏览**：突击步枪 / 霰弹枪 / 冲锋枪 / 精确射手步枪 / 狙击步枪 / 轻机枪 / 手枪 / 特殊
- **一套方案一张卡**：改枪码（一键复制）、改枪总价、方案概览图（点击放大）、属性柱状图
- **一把枪多套方案**：点枪名展开，切换「方案 1 / 方案 2 …」，每套都带一句定位说明
- **方案对比**：最多同时比 6 套，属性和价格逐行对齐，更优的一方绿色高亮，价格标出最省的一套
- **搜索**：按枪名或方案特点搜（例如搜「控枪」），按 `/` 直接跳到搜索框

## 怎么用

1. 左栏选分类 → 点枪名展开 → 选一套方案；
2. 点「复制改枪码」，进游戏粘贴导入；
3. 想比较几套：点方案右侧的 `+` 或页面上的「加入对比」，再到页面底部点「开始对比」；
4. 对比结果有独立网址，可以直接分享给别人。

## 说明

- 数据由玩家整理，**仅供参考，以游戏内实际数值为准**。
- 属性条目（后坐力控制、操控速度、射速、举镜时间…）因方案而异，缺项表示这套方案没有填写该数据。
- 标 ↓ 的属性表示**越低越好**（例如举镜时间、重量），对比时会优先高亮更优的一方；其余属性越高越好。
- 「改枪总价」按方案里填写的价格汇总，不同区服价格可能有出入。
